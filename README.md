# Thejovati Narayanan — Personal Portfolio

A personal portfolio website that introduces who I am, what I work on, and what interests me beyond the classroom. Inspired by the idea of an Indian thali, the website presents different sides of me as six distinct experiences.

**Live website:** https://thejovati256-hub.github.io/ThejovatiPortfolio/

## About the Project

This portfolio was built to bring together my background, skills, projects, experiences, and interests in one place. Its thali-inspired design reflects the different parts of my personality and gives visitors an interactive way to explore them.

## Features

- **About Me:** My background, education, and interests.
- **Interactive Thali:** Six sections representing different sides of me.
- **Skills:** Tools, technologies, and skills I am developing.
- **Projects:** Selected projects and work.
- **Experience and Leadership:** My research, internship, leadership, and volunteering experiences.
- **Beyond Class:** Interests outside academics.
- **Contact:** Email, social links, and a contact form.
- **Responsive Design:** Layout adjustments for desktop and mobile screens.
- **CV Download:** A downloadable copy of my CV.

## Technologies Used

- HTML
- CSS
- JavaScript
- Git and GitHub
- GitHub Pages for hosting

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.

The website is also available online at the live link above.
